## 四、采集合规与可行性建议

### 可行方案分级
- **Tier 1（优先攻关）**: 中国招标投标公共服务平台、中国政府采购网 — 法定免费，信息量最大
- **Tier 2（政府平台）**: 各省级公共资源交易中心 — 公开可浏览，需处理反爬
- **Tier 3（央企平台）**: 头部央企独立平台 — 部分免费，CA登录门槛
- **Tier 4（商业平台）**: 千里马/采招网等 — 收费，但数据质量高

### 共性问题
1. gov.cn域名普遍有WAF反爬（阿里云/腾讯云WAF、Cloudflare）
2. 多数平台需CA数字证书登录才能看详情（标题通常公开）
3. SPA架构占比高（Vue/React），需headless browser
4. 央企SaaS平台（国信e采/中招联合/优质采）可尝试统一对接

### 推荐对接优先级
```
P0: cebpubservice.com (法定公告源, 免费)
P1: ccgp.gov.cn (政府采购, 免费)
P1: 各省公共资源交易中心 (gov域, 信息量大)
P2: 头部央企平台 (中石油/中石化/国铁/中建等)
P3: 商业聚合平台 (千里马/采招网, 需付费)
```
